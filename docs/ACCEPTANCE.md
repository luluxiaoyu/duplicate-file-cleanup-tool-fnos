## 安装运行

1. 使用仅包含测试文件的授权目录；安装对应架构 FPK：`appcenter-cli install-fpk <包路径>`。
2. `appcenter-cli start duplicate-file-cleanup-tool-fnos`，确认进程 UID 为包用户且仅有 target/app.sock，无 TCP 服务端口。
3. 管理员及普通用户分别登录；检查深浅主题、移动端和独立浏览器授权回调。
4. 每个用户授权不同目录，验证无法读取对方的任务或通过伪造请求 UID 获取对方数据。

## 文件与空间

准备独立副本、硬链接、reflink、部分共享文件、压缩文件、稀疏文件、快照引用、空文件及中文长路径。依次验证：

- 完整内容相同才归组；同大小不同内容不归组；不跟随符号链接或隐式进入子挂载。
- 共享标志不能单独证明与组内保留文件共享；已有硬链接和重复合并不重复记收益。
- Btrfs 合并保留路径，后续写入其中一份不改变另一份；ext4 禁用 Btrfs 选项。
- 硬链接替换后 inode 相同；跨挂载、跨 Btrfs 子卷或元数据不兼容时拒绝。
- 回收站不记空间释放，恢复不覆盖同名文件，永久清空需确认。
- 结果分别展示逻辑大小、估算释放、统计完整性、回收站待清空、带采样时间的各文件系统可用空间变化。其他程序写入导致负变化时不能改成零。

## 拒绝和恢复

- 撤销授权、移除用户 ACL、缺 Token/Scope、开放 API 不可用时停止访问，页面给出重试或授权提示，不打印 Token。
- 路径穿越、NUL、符号链接、替换竞态、任务 ID 越权均被拒绝。
- 清理前修改文件、删除参考文件、制造恢复目标同名冲突；确认无静默覆盖和无错误删除。
- 分别在 prepared / staged / linked / swapped / deleting / committing 状态终止进程后重启；手动继续，核对文件身份和保留副本，不盲目重复操作。
- 模拟任务盘满、回收站目录不可写、日志无法提交、文件系统只读和 Socket 失败；检查原文件、暂存文件及任务记录。
- 应用中心停止任务后重启，验证状态为中断；卸载保留／删除应用数据均不得删除外部授权目录中的文件。

如网关无法连接 Socket，检查网关进程身份及 Socket 权限；不得通过 chmod 666 或增加无鉴权公网端口绕过。
